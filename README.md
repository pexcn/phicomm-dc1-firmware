# ESP DC1
**斐讯DC1智能排插个人固件.**

## WHY
众所周知的原因，斐讯服务器已经不能正常访问，插座的APP控制已经无法正常实现，需要有另外的方式实现插座的控制。

已有的方法为内网劫持实现，具体可参考[这里](https://bbs.hassbian.com/thread-5637-1-1.html)。

这次要实现的是通过一个自定义的固件，来完整实现DC1联网控制。

## 特性

本固件使用斐讯DC1插线板硬件为基础,实现以下功能:

- [x] 4个USB充电
- [x] 按键控制所有插口通断
- [x] 控制每个接口独立开关
- [x] 网页上传固件升级
- [x] WEB配置页面
- [x] MQTT服务器连接控制
- [x] 通过MQTT连入Home Assistant
- [x] 电压/电流/功率/视在功率/无功功率/功率因数/用电量统计(不做任何精度保证)
- [x] 过载保护

## 数据保存

- 配置仅在修改时保存，相同内容不重复擦写。
- 电量每 8 小时、跨日和手动清零时保存，重启后恢复上次快照；意外断电可能丢失尚未保存的增量。
- 需要断电记忆的开关状态在最后一次变化的 2 秒后合并保存。开关记忆和电量使用 LittleFS，独立于 Wi-Fi、MQTT 配置区。

首次升级若提示存储未就绪，在 **系统维护 → 用电统计与存储** 中点击 **初始化存储**，再保存其他设置。挂载失败不会自动格式化；主动初始化损坏的存储可能清除历史记录。已有 Flash 记录会兼容迁移，之前仅存于 RAM 的电量无法恢复。

只上传应用固件，不上传文件系统镜像或执行整片擦除。降级到旧固件可能覆盖运行数据。

## 如何编译
Visual Studio Code + PlatformIO ID 开发  [安装](https://www.jianshu.com/p/c36f8be8c87f)

网页源码在 `web/`，使用原生 HTML、CSS、JavaScript，无外部库或 CDN。PlatformIO 编译时自动压缩并嵌入应用固件，不需要单独上传文件系统。桌面使用侧边导航，手机使用抽屉导航；浅色为绿色主题，深色为雾蓝灰，主题偏好只保存在浏览器。

`src/` 是 DC1 设备逻辑，`lib/esp_framework/` 是仓库内维护的通用模块（配置、联网、Web、MQTT、日志与时钟），由 PlatformIO 自动发现和编译。`platformio.ini` 的 `lib_deps` 声明需要下载的外部依赖。修改配置协议后，运行 `python scripts/generate-protos.py` 更新生成文件；先执行 `pio pkg install` 安装依赖。
